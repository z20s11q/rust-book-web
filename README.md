# Rust 编程语言（精简版）· 网页版

单页连续浏览的静态站点，样式参考官方 Rust 书的网页排版。

## 打开方式

直接双击 `index.html` 即可，无需服务器、无需联网、无需构建。

```
site/
  index.html          单页全文（约 1.7 MB，含全部高亮样式）
  assets/
    style.css         排版样式（亮色 / 暗色两套主题）
    app.js            目录高亮、筛选、主题切换等交互
```

## 功能

- 左侧固定目录，两级层级，滚动时自动高亮当前章节，目录会跟随滚动。
- 顶部筛选框可按关键词过滤目录，快捷键 `/` 聚焦，`Esc` 清空。
- 右上「主题」按钮切换亮色 / 暗色，选择会记住。
- 右下回到顶部按钮。
- 窄屏（手机 / 平板）自动折叠侧栏，点左上角按钮展开。
- 全文连续不分页，可用浏览器 `Ctrl+F` 直接全文搜索。
